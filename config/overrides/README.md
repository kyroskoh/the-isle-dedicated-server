# ini overrides

Put `Game.ini` and/or `Engine.ini` here to set **any** key, including keys the scripts don't know.
They are merged into the generated files on every start (native and Docker).

Start from the examples in [`../examples/overrides/`](../examples/overrides/) and the references in
[`../reference/`](../reference/). Your `.ini` files in this folder are git-ignored.
