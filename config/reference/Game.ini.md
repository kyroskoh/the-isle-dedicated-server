# Game.ini reference (The Isle - Evrima)

Every `Game.ini` key known to this project. **Status** says how sure we are:

- **core**: widely used in community server guides and generated by these scripts since v1.0
- **community-documented**: reported by server operators. Name or behaviour may change between patches
- **UE**: a standard Unreal Engine key

Set a key in one of two ways:

1. Through its `server.conf` key (column 4). The scripts render and validate it.
2. Directly in `config/overrides/Game.ini` (see [`config/examples/overrides/Game.ini`](../examples/overrides/Game.ini)).
   Any key works there, including ones not listed here.

## `[/Script/Engine.GameSession]`

| Key | Type | server.conf | Status | Description |
|---|---|---|---|---|
| `MaxPlayers` | int | `MAX_PLAYERS` | UE | Engine-level player cap (kept equal to `MaxPlayerCount`) |

## Lists

Repeat a list key once per value:

```ini
AllowedClasses=Tyrannosaurus
AllowedClasses=Triceratops
```

The `admins`, `whitelist`, `classes` and `ai-classes` commands manage these for you.
